# BBQ v1.2.0 — Interaction, Customization & Stability

BBQ v1.2.0 makes the desktop island more interactive, customizable and reliable.

---

## Highlights

- **Theme Switcher & 11 System Accent Colors**: Seamless Light, Dark, and System appearance modes with 11 curated platform accent colors and dynamic hex picker derivation.
- **Custom Hotkey Recorder**: Interactive recorder supporting arbitrary multi-modifier shortcut combinations (e.g. `Ctrl+Shift+B`, `Ctrl+Alt+Space`, `Alt+Shift+B`, `Win+Shift+B`).
- **Launcher 2x2 Quick Actions**: Streamlined, zero-overflow 2x2 quick actions grid designed to fit natively inside the expanded island.
- **Mouse Wheel Tab Navigation**: Fast, fluid widget navigation by scrolling the mouse wheel across the island header with boundary clamping.
- **Timer Modes & Custom Presets**: Countdown, Stopwatch, and Pomodoro with guaranteed idle mode initialization and quick-select presets.
- **Persistent Settings & Onboarding Hardening**: Synchronous `localStorage` caching coupled with SQLite database persistence guarantees zero startup flash and eliminates repeat welcome tours.

---

## What's New

### Theming & Personalization
- **Theme Switcher**: Instant switching between Light, Dark, and System modes with immediate DOM token reflection.
- **11 System Accent Colors**: System Blue (new default), Red, Green, Orange, Yellow, Pink, Purple, Indigo, Teal, Mint, and Cyan.
- **Light/Dark Accent Mapping**: Every preset maps to authentic system Light and Dark values (e.g., Light Blue `#007AFF` vs Dark Blue `#0A84FF`).
- **Custom Accent Color Picker**: Dynamic hex color picker automatically deriving hover, glow, and subtle opacity tokens in real time.
- **Compact Size Sliders**: Real-time slider controls for compact island width (180px–480px) and height (36px–54px).
- **Modern Switch Controls**: Accessible, smooth switch toggles replacing legacy controls.

### Navigation & Interaction
- **Custom Hotkey Recorder**: Capture multi-modifier combinations directly in Settings.
- **Mouse Wheel Tab Navigation**: Smooth horizontal widget navigation with debounced boundary handling.
- **Custom Timer Presets**: 1m, 5m, 10m, 15m, 25m, 45m, and 60m focus intervals.
- **Launcher 2x2 Quick Actions**: Symmetrically aligned quick access buttons for Files & Workspace, Downloads, Home Directory, and Lock Screen.

## Improvements

- **Timer Mode Switching**: Switching between Countdown, Stopwatch, and Pomodoro always initializes the newly selected mode in an idle state; timers never auto-start unexpectedly.
- **Hover Geometry**: Symmetrical 4-directional expansion around the visual center with zero cursor jitter.
- **Interaction Handling**: Inside clicks preserve expanded state; outside click detection via `composedPath()` reliably collapses the island.
- **Launcher Layout**: Engineered to fit strictly within the 400x280 expanded island container with zero vertical or horizontal overflow.
- **Theme/Accent System**: Dynamic CSS variable derivation with instant zero-flash stylesheet updates.
- **Settings UI**: Clean, modern design tokens with categorized preferences and real-time visual feedback.
- **Persistence**: Synchronous `localStorage` caching paired with asynchronous SQLite database synchronization.

---

## Bug Fixes

- **Timer Auto-Start on Mode Switch**: Prevented active session timers from leaking and auto-starting upon switching modes.
- **Hotkey Recorder Limitation**: Removed restriction limiting global shortcuts to `Ctrl+Space`, enabling arbitrary valid key combinations.
- **Launcher Overflow**: Resolved bottom action clipping and eliminated scrollbars within the expanded island.
- **Settings Persistence on Restart**: Fixed startup gate deadlock that prevented SQLite settings from hydrating if `onboarding_completed` was not pre-set in memory.
- **Welcome / Onboarding Restart Regression**: Fixed startup gating so completed tours are remembered across restarts without repeating the welcome modal.
- **Custom Accent Color Loss**: Guaranteed custom hex colors are preserved when switching between system presets or restarting the application.
- **Hover Jitter**: Debounced pointer transitions and eliminated redundant hover state re-notifications.
- **Outside-Click Interaction**: Guaranteed deterministic island collapse on external backdrop clicks.

---

## Performance & Reliability

- **Resource Budget**: Idle working set under 60 MB RAM; 0.0% idle CPU utilization.
- **Zero Polling Loops**: Timers and animations rely strictly on system clock deltas and event triggers.
- **100% Local-First Privacy**: Zero telemetry, zero analytics, zero external network requests.
- **Offline Self-Contained Execution**: Embedded frontend assets; completely decoupled from Vite dev server.
