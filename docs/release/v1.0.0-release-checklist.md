### Known Limitations
1. **Unsigned Binaries**: Windows SmartScreen will display an unknown publisher alert upon first launch. macOS Gatekeeper requires right-click -> Open until an Apple Developer ID certificate is configured.
2. **Linux Wayland**: Certain compositors restrict global hotkey intercepting and top-center overlay positioning; BBQ gracefully falls back to standard windowing and in-app hotkeys.
3. **Multi-DPI Secondary Monitors**: Switching between monitors with divergent DPI scales on Windows requires a display event to recalibrate window geometry.
